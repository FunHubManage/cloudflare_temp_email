# 管理后台

> [!NOTE]
> 需要配置 `ADMIN_PASSWORDS` 或者 `ADMIN_USER_ROLE` 才可以访问管理后台
> 管理员角色配置：如果用户角色等于 `ADMIN_USER_ROLE`，则可以访问管理后台

部署前端应用之后，点击左上角 logo 5 次或访问 `/admin` 路径即可进入管理后台。

需要在后端配置 `ADMIN_PASSWORDS` 或者当前用户角色为 `ADMIN_USER_ROLE`，否则不允许访问管理后台。

## 管理员密码和用户账号的区别

`ADMIN_PASSWORDS` 是管理后台的管理员密码，不是站点用户账号，也不对应某个邮箱地址。使用管理员密码登录后可以进入后台，但它本身不能收信。

站点用户账号存储在 `users` 表中，需要通过用户登录体系进入；用户是否能收信取决于是否创建或绑定了邮箱。即使你创建了一个用户邮箱为 `admin@example.com` 或用户名看起来像 `admin` 的普通用户，它也不会自动获得后台权限。

如果希望某个用户也能进入管理后台，请配置 `ADMIN_USER_ROLE`，并在用户管理中给该用户设置相同的角色。

## 邮箱列表排序

管理后台的「邮箱管理 → 邮箱列表」支持按列排序，可点击表头进行升序/降序排列：

- ID
- 邮箱地址
- 创建时间
- 更新时间
- 邮件数量
- 发送数量

搜索邮箱地址时，分页会自动重置到第 1 页。

## 群发邮件

在管理后台的「邮件管理 → 群发邮件」中使用，标签页位于「发送邮件」旁边，仅管理员可访问。群发沿用现有的[发送邮件配置](../config-send-mail)，不需要新增环境变量、API 或数据库迁移。

### 收件人与个性化内容

1. 填写发件邮箱、发件人名称、主题和正文。正文支持纯文本、HTML 和富文本。
2. 点击收件人表格左下角的「+」单独新增一行；点击旁边的下拉菜单，选择「批量添加收件人」，在弹窗中粘贴邮箱，每行一个，也支持逗号或分号分隔。每批最多 100 位收件人；粘贴时不区分大小写跳过重复地址，并提示、保留无效地址供修正。收件人表格中的无效或重复地址会阻止发送。
3. 点击表格右上角的「+」增加变量列，每列自动获得固定的 `{{var1}}`、`{{var2}}` 等占位符。给每位收件人填写各列的值，在主题或正文中插入占位符即可生成不同的邮件；通过列标题旁的移除按钮删除变量列，其他列的编号不会改变。新增列使用当前最小的空缺编号，全部删除后从 `var1` 开始；复用编号的列需重新填写变量值。
4. 在预览中选择收件人，核对替换后的主题和正文，确认后开始发送。桌面端左侧编辑区较窄，右侧预览随页面宽度伸缩，最大宽度为 900px，高度与左侧编辑区一致，长邮件在预览框内滚动；窄屏和手机上预览移到编辑区下方。

例如，主题为 `{{var1}}，邀请你合作`，正文包含 `我们看过你关于 {{var2}} 的作品`。给不同收件人填写不同的姓名和创作领域，就能分别生成对应内容。变量值作为普通文本使用，HTML 和富文本中的变量应放在可见正文中，不要用于标签、属性或链接地址。变量标记应保持完整，避免用加粗等格式把标记拆开。

### 发送进度与恢复

邮件逐封发送，每封只有一位收件人，其他收件人互不可见；前一封结束后至少间隔 2 秒再发下一封。开始后使用本批确认的内容，不会随草稿编辑而改变。请保持浏览器页面打开；管理员页内切换标签页可以继续发送，离开管理后台、退出登录或身份变化会暂停后续邮件。

可以手动暂停，当前正在发送的一封会等待结果。遇到错误也会自动暂停；超时、断网或无法确认渠道结果时显示「结果待确认」，邮件可能已经发出。系统不会自动重试，也不会在点击继续时重发失败、结果待确认或已经成功的邮件，只会继续「待发送」项。

草稿和进度保存在当前标签页的浏览器会话中。刷新后任务保持暂停，刷新前仍在发送的邮件会标记为「结果待确认」；确认情况后可手动继续待发送项。它不是后台任务，也不提供跨设备恢复或关闭页面后继续发送。

发送仍受现有渠道和站点的日/月额度限制。成功表示发信渠道已接受邮件，不代表已送达或被阅读；请通过「已发送」记录和渠道后台核对结果待确认的邮件，再决定是否另行发送。

## 如果你的网站只可私人访问，可通过此禁用检查

`DISABLE_ADMIN_PASSWORD_CHECK = true`

## IP 黑名单 / 白名单

在管理后台的 **IP 黑名单设置** 页面可配置访问控制，作用于以下接口：创建邮箱地址、发送邮件、外部发送邮件 API、用户注册、验证码校验。

### IP 白名单（严格模式）

启用后，**仅**匹配白名单的 IP 才能访问受保护接口，其他所有 IP 一律返回 403。

- 纯文本条目：精确匹配（不支持子串），例如 `1.2.3.4`
- 正则条目：使用锚定正则，例如 `^192\.168\.1\.\d+$`
- 白名单命中的 IP 会跳过黑名单检查
- 白名单启用但列表为空时，服务端忽略该开关（防止锁死）

### IP 黑名单

启用后，匹配黑名单的 IP 返回 403。支持文本子串匹配或正则表达式。

### ASN 组织黑名单

按运营商/ISP 拉黑，不区分大小写，支持文本匹配或正则。

### 浏览器指纹黑名单

按 `x-fingerprint` 请求头拉黑，支持精确匹配或正则。

### 每日请求限流

限制单个 IP 每天最多请求次数（1–1,000,000），超出返回 429。计数以 UTC 日期为周期，24 小时后自动重置。
